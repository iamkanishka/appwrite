# Installation

## Requirements

- Elixir `~> 1.18`
- Erlang/OTP 26 or later

## Adding the dependency

Add `appwrite` to your `mix.exs`:

```elixir
def deps do
  [
    {:appwrite, "~> 1.0"}
  ]
end
```

Then run:

```bash
mix deps.get
```
